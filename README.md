## 🙋‍♂️ 关于我

你好，我是 **88lin**，一名 AI 研究者与 Agent 工程实践者。

我追踪 AI 领域的最新进展，但更在意它们能不能落地：用 Agent 工作流把复杂需求，拆成可交付、可维护、可复盘的工程结果。

前沿跑得快，地基更要稳——算法与计算机科学的核心基础，是我并行推进的第二条主线。

> Turning the AI frontier into shippable engineering.
